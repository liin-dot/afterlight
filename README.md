# 烬夜 AFTERLIGHT · 长夜重铸

原创像素生存游戏：进入遗忘墓园，回收灵光，组合武器与遗物，活过十分钟并击败蚀月君王。原生 Canvas 2D、ES Modules 与 Web Audio，零运行时依赖。

## 启动

需要 Node.js，无需安装依赖：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173/>。也可部署到静态服务器；浏览器模块需要 HTTP 服务，不能直接打开 HTML 文件。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 幽影冲刺 | WASD、方向键 / 空格 |
| 选择升级 | 1、2、3 或点击 |
| 预览附近祭坛挑战 / 确认接受 | E 或点击挑战提示 / 预览中按 E |
| 远征菜单 / 返回 | Esc、P |
| 角色状态 / 天赋树 / 融合手记 / 道具图鉴 | C / T / G / I |
| 菜单内重新开始 / 返回营地 | R / Q |
| 声音 / 全屏 | M / F |

触屏显示摇杆与冲刺按钮。武器自动攻击。状态、图鉴、菜单均暂停战斗；从升级页查看后返回会保留原来的选项。重新开始和退出营地会先结算余烬与发现记录。

战斗 HUD 将生命、时间、暂停及天赋／融合／图鉴入口收在顶部。手机底部以「装备」入口查看完整武器与道具，摇杆和冲刺贴近下方两角；桌面只显示实际装备的图标，空槽不占画面。被动蓄力仍显示在天赋按钮底边和角色脚下，天赋可学／融合就绪时入口高亮。远处和未开放的祭坛不显示常驻卡；靠近后预览会暂停战斗，确认才开始，挑战中只保留目标进度与时间。

## 战场探索

地图八座祭坛提供三类可选挑战。靠近后按 **E** 或点击提示，暂停查看目标、风险与奖励，再确认开启；路过祭坛不会自动治疗。指南针指向最近的未使用祭坛，挑战开始后指向本次祭坛或猎影守卫。

| 挑战 | 目标 | 奖励 |
| --- | --- | --- |
| 守灯仪式 | 在灯圈内累计守护 12 秒，离圈暂停进度 | 护盾补至 12、20 余烬 |
| 猎影悬赏 | 击败召来的精英守卫 | 已有装备强化一次、25 余烬；无可强化装备则改为 24 基础经验 |
| 归魂引路 | 绕祭坛收回 6 枚魂光 | 30 基础经验、一次重铸，重铸最多储存 5 次 |

每次限时 **45 秒**，期间每 5 秒召来一组援兵，遵守当前敌群上限。每局同时只能进行一个挑战，每座祭坛只可尝试一次。开局 45 秒后开放，首领登场前 25 秒及存活期间暂停开启，九分钟后关闭新挑战。首领到来会中止当前挑战；暂停菜单也会暂停挑战时间。结算页记录完成与未完成次数。

## 角色与局内天赋

三名角色各有初始被动、三条天赋分支与九个节点，共 **3 种初始被动、27 个升级节点**。被动从出征开始生效，不占武器或道具位置；所有节点均改变对应被动的蓄积、触发或命中效果。

| 角色 | 默认能力 | 三条成长路线 |
| --- | --- | --- |
| 守灯人 | 自带 8 护盾；近身武器命中积蓄灯火，六层触发震荡并补盾 | 薪火：五层蓄满、燃烧与回响；灯壁：厚盾、回复、储存灯芯；征途：冲刺添火、破围、加速蓄放 |
| 逐星者 | 一颗独立伴星自动发射追踪星火 | 星群：四伴星与穿透；寒月：星火减速、易伤、冻结；引星：星火标记、经验归巢、灵泉反哺星火 |
| 荒野客 | 移动积蓄猎风，下次武器施放追加穿透风矢 | 穿风：风矢增伤、穿透与三重追踪；游猎：缩短蓄势、冲刺充满、移动连射；追猎：风矢留痕、武器命中接力、强化追击 |

灯壁专精必须先积满灯火储存灯芯，才有本局一次的重燃机会。引星只回收星火标记期间死亡敌人的结晶，普通经验不会为灵泉充能；每次最多储存一份充能。追猎先由风矢标记，再由武器直接命中触发，追加风矢不能自行积累追击次数。敌人头顶的蓝色、绿色标记分别表示引星与风痕。

实战反馈更新：HUD 和角色脚下显示被动蓄力条，天赋页列出当前伤害、数量、间隔及本局触发次数；灯芯储存和灵泉触发有独立提示。学习后键盘焦点留在同一分支。灯火在冷却内蓄满后会自动释放，基础间隔调整为 6 秒以约束自动补盾，逐日仍为 2.5 秒。轻风同时将风矢间隔从 1.5 秒缩至 1 秒；灵泉所需引星经验为 30，专精后为 20，仍有 4 秒间隔。月蚀、猎魂目和陨星易伤分别计时，只取当前有效的最高倍率，较弱效果不会延长较强效果。

等级 **4、8、12、18、24、30** 各获得一个天赋点，每局最多六点。节点消耗一点，同列依次学习；第三层从 18 级开放，三种最终专精只能选择一种，其余点数可投入其他分支的前两层。天赋不消耗装备升级三选一，投入后本局不可撤回，重开时全部重置。

营地可以预览完整天赋树；顶部展示初始被动及触发流程，三条路线按「强化 → 联动 → 专精」展开。战斗 HUD 显示实际蓄力门槛、冷却、灯芯或引星充能状态。按 **T** 打开天赋树会暂停战斗；学习后立即更新被动与联动判断，返回升级页保留原选项、待选次数和重铸次数。结算伤害记录包含角色天赋造成的直接伤害。

天赋生成的追加攻击不会递归触发命中遗物或再次暴击。灼烧、冻结、治疗和补盾各自遵守描述中的间隔与上限；角色控制或燃烧能力也可为相关遗物提供触发条件。

## 本次重铸

总计 **81 种可发现道具**：16 种基础武器、20 种融合武器、14 种属性祝福、24 种联动遗物、7 种拾取物。基础武器的 16 种独立进化归入对应武器，不重复计数。

新增六件遗物：**牧魂契**强化灵魂与召唤武器、**霜行石**在冲刺起点冻结追兵、**腐时沙漏**强化附着燃烧与侵蚀、**碎灯棱片**在破盾时发射追踪棱片、**分岔骨钉**让武器暴击分裂追击、**蓄雷瓶**将雷电命中积成护身雷环。新增融合 **烬雪天灾**组合冻结陨星与冰火领域，**群星灵龛**组合穿透追魂召唤与消散震波。配方仍需要在游戏中亲手融合后揭晓。

- 新武器包括跳弹飞轮、延迟陨星、感应地雷、牵引锁链、固定石像与贯穿长枪。融合会组合攻击机制，例如陷阱加冻结、炮台加连锁、陨星加光束。
- 武器六格，属性祝福与遗物共用六个道具位。有限位置让输出、防御、控制与成长之间有取舍。
- 新属性包括范围、持续、弹数、暴击倍率、经验成长与诅咒。诅咒同时提升自身收益和敌方压力。
- 遗物可互相提供触发条件：寒髓针与霜纹镜、蚀骨针与孢子囊、不熄燃芯与死火余烬、护盾与反伤，以及火毒共存时的炼金爆炸。
- 升级卡显示实际数值变化、适配原因和消耗材料；状态页列出已生效组合，结算显示主要伤害来源和总伤害。遗物与次生效果合并计入单独一项。

## 十分钟节奏

`src/balance.js` 集中定义阶段、经验需求与选择权重。敌人生命、伤害、速度在分钟间平滑变化；敌群组成、密度与上限按阶段切换。

| 时间 | 战场变化 | 构筑重点 |
| --- | --- | --- |
| 00:00–02:00 | 骷髅、蝠群与食尸鬼逐步加入，一分钟起有少量幽魂远射 | 提高主武器等级，走位回收经验，避免停留在敌群中 |
| 02:00–03:00 | 怪物生命跟上主武器成长，开放武器独立进化 | 准备控制与第一组材料 |
| 03:00 | 墓园看守，开放隐藏融合 | 选择融合或继续独立进化 |
| 04:00–06:00 | 重甲单位增多，收割者出现 | 补足单体输出、防御和遗物联动 |
| 06:00 | 无名葬钟 | 利用攻击预警和冲刺处理首领 |
| 07:00–10:00 | 混合怪潮，幽魂散射，收割者蓄力突进 | 利用穿透、控制与清场补给维持路线 |
| 10:00 起 | 蚀月君王，降低普通敌群密度 | 躲避冲锋、地面预警和带缺口的环形弹幕 |

敌人按时间成长，不根据玩家等级、当前生命或装备强弱临时加血。普通敌人生命在 **2 / 4 / 6 / 8 / 10 分钟**分别达到开局的 **2.65 / 4.8 / 6.4 / 8.1 / 9.8 倍**，把压力集中在前中期，后期增幅趋缓。普通武器的伤害成长大致跟上敌人生命；生命上限不会随角色等级免费提高。单靠堆武器等级仍需走位，范围、穿透、控制与触发遗物的配合才会放大清场能力。

长刃基础伤害按一级至五级 **20 / 26 / 32 / 38 / 44** 成长，进化为 75，移除一级到二级翻倍的跳涨。连弩每箭为 **10 / 12 / 14 / 16 / 18**，进化为 40；第三、五级才增加箭数，与第二、四级的穿透提升错开。武器面板、升级预览和实战共用这些数值。融合成品的伤害不受这次基础武器调整影响。

骷髅、蝙蝠基础生命分别为 **32 / 26**。普通敌人在 0 / 60 / 120 / 180 秒的生命倍率为 **1 / 2.4 / 3.6 / 4.8**，中间连续插值，后半局平滑接回原有强度附近。血量在出生时确定，不会因玩家升级而临时增加；较早出生的旧怪、暴击、慢速重击及多来源联动仍可能快速击杀。

守灯人一级普通一刀约 22，满伤害祭坛约 25；荒野客两箭约 20，满祭坛约 24；逐星者游魂接触与伴星分别约 15 / 11。开局检查覆盖三角色实际攻击，还在不同时间、武器等级及永久加成下推进完整弩矢齐射与碰撞，避免把单箭不秒杀误当成整轮不秒杀。

普通敌人的基础接触伤害为骷髅 12、蝙蝠 9、食尸鬼 15、幽魂 14、骑士 21、收割者 19；随时间最高达到 2.14 倍。三位首领的接触及地面攻击分别造成 26 / 34 / 44 基础伤害，环形弹幕为其 65%。攻击预警与弹幕缺口提供躲避机会。三分钟与六分钟首领登场后，普通生成只放缓 12 秒；最终首领仍需击败才算通关。

受击保护为 **0.6 秒**，选择升级后的保护为 **0.45 秒**；冲刺的基础冷却和保护时间保持 3 秒 / 0.38 秒。永久祭坛的「春回之息」改为连续 **6 秒未受攻击**后恢复，护盾受击也会打断；本局选择的复苏苔芽、汲取与恢复天赋仍可在交战中生效。已购买的永久升级和存档继续保留，满祭坛也需要躲避攻击。

每级所需经验为 `round(18 + 6 × (等级−1) + 1.4 × max(0, 等级−5)^1.65)`。到角色四级的累计需求由 36 提高至 72，减缓早期「秒杀 → 连续升级 → 更快秒杀」循环。三个种子的收集代理中，新档第一分钟约四级、第二分钟七至八级、第三分钟十一至十二级；满永久祭坛约五／九／十三至十四级。拾取范围和经验倍率分开成长；合并远处结晶时保留全部经验。

药草恢复 **12 生命**，满血时留在地上，掉落共享 20 秒间隔，地面最多一株。常态 / 低于 45% 生命时的掉落率为 0.4% / 1.2%；低生命、场上无药草且距上次掉落至少 75 秒时，下次击杀提供补偿。冻结、清场、护盾、全场吸取是稀有战术补给。精英宝箱强化一次已有装备，首领宝箱强化两次并恢复 10 生命；满级或放逐装备不参与抽取。

## 权重与构筑

所有武器和道具有构筑标签：近战、远程、火焰、寒霜、雷电、侵蚀、灵魂、召唤、范围、控制、暴击、守护、游击、成长。猩红誓约、时隙沙漏等全局强化标为「通用」，不为所有流派重复投票。升级卡、道具状态和图鉴都会显示标签，图鉴也支持按标签名称搜索。

本局最近 **12 次主动装备选择**形成偏好。最新选择贡献 1 份信号，每向前一次乘 **0.82**；多标签道具平均分配信号，避免标签多就天然占优。现有装备提供较弱的基础信号（每件 `0.18 + min(4, 等级−1) × 0.04`）。候选的最强匹配标签加上第二匹配的四分之一，形成 `1 + 1.6 × min(1, 信号 / 3)` 倍率，最高 **×2.6**。

选择火焰会逐渐提高火焰及相关范围道具的权重，转向寒霜后旧信号衰减，新的控制、冰雷搭配更容易出现。只记录实际选择成功的装备与融合；查看、重铸、放逐、跳过、宝箱和天赋学习不冒充主动装备选择。宝箱强化会改变当前装备的弱信号。本局偏好重开即清空。

常见、精良、稀有的基础权重为 **100 / 70 / 42**，不是最终抽中概率。已有武器乘 2.25、已有道具乘 1.7；有触发来源的遗物乘 1.8，缺少来源的乘 0.22。相关融合材料乘 1.25、补齐遗物触发来源乘 1.8、角色专长乘 1.18，最后再乘标签倍率。降低固定偏置，让本局实际选择发挥更大的作用。

升级尽量保留一项已有武器强化，开局优先提供第二种武器；每四级在有剩余选项时提供适配遗物。可用融合、已发现且正在追踪的材料优先。满槽、满级、已消耗或已放逐的装备不会挤占不适用的选项。

从 5 级开始，若保底选择后仍有空位，有 **22%** 的机会抽取一件标签加权较弱的新装备，标为「转型机会」；需要有可用装备位，遗物也须具备触发来源。其余候选仍正常按权重抽取，不匹配的标签不会被清零。卡上的「标签加权」仅表示标签倍率，不能当作最终出现概率。

每局有三次重铸和三次放逐。重铸降低上一组选项再次出现的权重；放逐刷新选择，并让该装备退出本局升级与宝箱池，已有属性保留但不释放位置。也可跳过当次成长换取 10 余烬。无可用升级时改为治疗与余烬。

武器及预览共用 `src/stats.js`。持续状态伤害不暴击，也不重复触发命中遗物；连锁、尸爆、汲取和反伤各有对应限制。护甲减伤仍保留至少 30% 的原始伤害，护盾按上限补充，不能无限累加。

成型融合的回报集中在后两级：融合伤害统一系数由原来的各级 0.86，改为 **0.90 / 1.02 / 1.14**，再叠加各武器自身等级效果和构筑加成。完成材料、强化成品和遗物联动后，可以在中后期持续清扫怪潮；纯输出构筑仍要躲避漏网攻击。冻结中的敌人不能造成接触伤害；寒狱星环的牵引止于寒晶环，不会直接把敌人拉进角色体内。

## 发现与融合

三分钟后，双武器路线需要指定武器各四级，武器与遗物路线需要武器五级、遗物二级。未知配方照常判定，满足后升级会出现未知融合卡；亲手选择并成功融合才揭晓成品并永久记录。

融合消耗材料的全部等级，材料的独立效果失去且本局不再出现。双武器合为一格；消耗遗物会释放一个道具位。成品从一级开始，每件六级武器或满级遗物贡献一级继承，最高三级。宝箱只强化，不自动融合。

图鉴记录实际获得的道具及最高等级，支持搜索、分类、各级数值和已发现搭配。配方追踪仅用于已发现的路线。继续使用原 localStorage 存档，保留余烬、祭坛、战绩和已有发现；旧融合记录可补录其材料的最低已达等级，未曾保存的普通道具获取历史无法追溯。

存档读取会校验数值与祭坛等级。购买和结算会读取最新余额，并通过浏览器 Web Locks 顺序写入，避免多个标签页互相覆盖；永久升级只影响下一局。写入失败时奖励留在当前页等待后续写入重试，购买不扣款、不授予未保存升级。没有 Web Locks 的旧浏览器仅保证同一页面内的顺序写入。

```sh
npm run check -- --talents
npm run check -- --simulate
node tools/check-balance.mjs --browser
```

同一个原生 Node 检查脚本覆盖全部武器数值、72 次实际攻击、20 条融合交易、六格约束、标签覆盖、偏好累积与转型、权重上限、触发条件、六件新遗物、护盾与补给，以及 27 个天赋节点的学习条件、六点上限、重置、默认能力、伴星控制、冲刺、震荡回响和一次致命保护。模拟使用实际游戏循环并花费天赋点，输出三名角色的生存代理和关闭受伤的收集代理结果到 `artifacts/balance-report.json`。它用于比较成长节奏，不代表真人通关率。

`--pressure` 在固定时间与装备下对照站桩和走位，共九种配置、五个种子、90 个一分钟场景。包含满永久祭坛，以及同为 37 点装备预算（计入被消耗的融合材料）的普通武器、冰雷、血火和连锁构筑。保留自然怪潮与补给，排除首领、新升级和地图祭坛，结果写入 `artifacts/pressure-report.json`。检查前中期必须走位、满祭坛不能代替走位，以及成型连锁构筑的清场优势；另有永久恢复中断、冻结接触与寒域牵引边界的直接检查。

`--opening` 从零秒运行三角色 × 新档／满永久祭坛 × 三种子，共 18 局三分钟收集代理。真实拾取经验、优先强化起手武器，记录二／三／四级时刻、等级、经验回收及满血骷髅／蝙蝠的起手武器普通单次命中秒杀率，保存到 `artifacts/opening-report.json`。检查升级间隔与阶段等级范围，并要求每组各分钟有足够命中样本，骷髅／蝙蝠单击秒杀率不超过 20%／35%。禁用受伤和暴击以隔离成长速度；它不是通关率，也不统计一轮齐射或多武器同时命中的总伤害，完整齐射另由基础检查验证。

`--weights` 固定同一套装备、角色、时间与随机种子，为无偏好、火焰偏好、寒霜转型各抽取 600 组三选一，结果写入 `artifacts/weight-report.json`。多标签道具会同时计入多个标签，因此标签计数不应相加作为总候选数。

`--talents` 比较九条专精，每条三个固定种子，共 27 局：同角色相同装备、LV24、五分钟起点、65% 初始生命，实际走位循环运行至一分钟或死亡。报告记录生存、天赋输出、灵泉、冰爆、追猎和引星回收，保存到 `artifacts/talent-report.json`。这是分支功能与压力对照，不代表不同路线输出相等或真人通关率；支持路线仍需要武器和防御构筑。基础检查还覆盖易伤独立过期、满灯自动释放和显示范围。

浏览器检查需先启动本地服务，并安装 Windows 版 Chrome（脚本使用默认安装路径）。它检查桌面、触屏布局，升级倾向、标签搜索、放逐、两条新增融合、结算、三名角色的天赋树、键盘与触屏学习、专精锁定及返回时保留升级选择，并保存截图到 `artifacts/`。截图与临时浏览器配置不进入版本控制。

基础检查另覆盖三类祭坛的真实奖励、离圈暂停、超时、首领中止、死亡、一次性结算与援兵上限，以及异常存档、陈旧快照、购买核价和失败重试。浏览器检查包含祭坛键盘／触屏交互及两个独立页面同时购买、结算的事务检查。
