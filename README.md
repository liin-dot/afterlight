# 烬夜 AFTERLIGHT

一款原创像素风自动战斗生存游戏。独自进入遗忘墓园，收集灵光，进化武器，活过十分钟并击败蚀月君王。

## 启动

需要 Node.js，无需安装依赖。

```sh
cd afterlight
npm start
```

浏览器打开 http://127.0.0.1:4173 。也可以将整个目录部署至任意静态网页服务器。不要直接以 `file://` 打开，游戏使用浏览器 ES Modules。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 幽影冲刺（短暂无敌） | 空格 |
| 选择升级 | 1 / 2 / 3 或鼠标 |
| 远征菜单 / 返回 | Esc / P（战斗及升级选择时均可打开） |
| 重新开始 | 远征菜单内按 R，或点击「重新开始」 |
| 退出到营地 | 远征菜单内按 Q，或点击「退出到营地」 |
| 角色状态 / 关闭状态面板 | C（Esc 也可关闭） |
| 武器融合图谱 | G |
| 永久道具图鉴 | I |
| 声音 | M |
| 全屏 | F |

触屏设备显示左侧摇杆和右侧冲刺按钮。武器自动攻击，无需瞄准。

右上角「菜单」提供继续、重新开始和退出到营地。升级选择页与局内状态 / 图鉴底部也有菜单入口；从升级选择进入菜单再返回，原选项、待升级次数和重铸次数保持不变。

「重新开始」先结算当前远征，再使用同一角色从 00:00、LV.1 和起始武器开启新一局。「退出到营地」结算后直接回到角色选择页面。两者都会保留本局已获得余烬、永久成长和图鉴发现，本局等级与装备在下一局重新获得；R / Q 仅在远征菜单内生效。

点击左上角角色栏或按 **C** 查看角色状态；点击底部已装备武器可直接查看其效果。暂停、升级和结算界面也有状态入口。查看期间战斗、冷却与计时停止，关闭后返回原界面；从升级界面进入不会消耗重铸次数或改变候选项。

状态面板显示生命与经验、实际伤害倍率、冷却缩减、移动速度、护甲、回血、拾取范围、经验倍率、暴击与冲刺数据，并注明加成来源。武器页显示当前装备等级、实际效果与下一阶段数值、被动道具的累计效果，以及拾取物说明。营地入口预览所选角色下次出征时的属性；远征中的祭坛加成以出征时为准。

## 永久道具图鉴

按 **I**，或点击营地的「道具图鉴」、战斗 HUD 的图鉴按钮，查看历次远征已发现的装备。角色状态新增第四页图鉴；暂停、升级选择和结算页也可直接进入。局内查看会暂停战斗，关闭后恢复原界面，保留升级选项和重铸次数。

- 图鉴收录 39 种内容：10 种基础武器、9 种融合武器、8 种属性祝福、8 种联动遗物与 4 种拾取物。进化作为对应武器的 6 级预览，不单独计数。
- 出征获得起始武器、选择升级、宝箱强化或实际拾取时立即记录发现及历史最高等级；仅看见升级候选不算获得。
- 记录不依赖当前装备，消耗材料、远征结束、返回营地或刷新页面后仍能查阅。融合武器仅在实际融合成功后收录。
- 支持分类、名称与效果搜索、各等级数值预览、获得方式、联动条件及已发现配方跳转。可切换无加成的基础值和按角色当前加成计算的预览值，查看不会装备或升级道具。
- 联动搭配和配方只引用已发现的条目，避免提前揭晓未知融合。
- 兼容原存档：从已有融合发现恢复成品及其材料的最低已达等级。旧版本未保存的普通道具获取历史无法追溯，从此次更新后开始记录。

## 发现制融合与联动遗物

按 **G** 打开融合手记。图谱只展示在当前浏览器中亲手融合成功的武器；未发现的名称、配方、图标与效果不会出现在图谱或基础装备的详情链接中。首次发现立即写入原存档，无需结束远征或通关；已有余烬、祭坛和战绩保留。

- 未知配方照常参与条件判定，不需要追踪，也不需要先在图谱中解锁。
- 双武器融合需要两件指定武器各达到 3 级；武器与遗物融合需要指定武器达到 4 级、指定遗物达到 2 级。具体搭配由玩家探索。
- 有可用配方时，下次生成升级选项保证提供一张融合卡。首次显示为未知融合，列明会消耗的材料；选择并成功铸成后才揭晓成品。
- 融合消耗材料的全部等级；消耗的武器与遗物本局退出升级池。道具的独立联动效果随之失去，融合武器使用自身固有效果。
- 双武器融合合为一格，释放一格；武器与遗物融合维持原有武器位数量。不同路线可能共用材料，已经消耗的材料会让其他相关路线在本局关闭。
- 成品基础为 1 级，已进化武器（6 级）、满级融合遗物（3 级）各增加一级继承，最高 3 级。升级与宝箱仍可强化融合武器；宝箱不会自动消耗材料融合。
- 只可追踪已经发现的配方。追踪从下次升级或重铸起优先提供缺失材料；当前三选一保持不变。营地追踪作用于下局。

新增基础武器：回旋月镰（往返切割）、黑棘毒瓶（毒池与侵蚀）、送葬铜钟（延迟回响）、裂光棱镜（穿透光束），各有独立进化。

| 联动遗物 | 触发方式 |
| --- | --- |
| 不熄燃芯 | 刃器或投射物命中时点燃 |
| 引雷针 | 投射物或光束命中时连锁引雷 |
| 霜纹镜 | 攻击减速、冻结敌人时碎冰 |
| 孢子囊 | 侵蚀敌人死亡时毒爆并传播 |
| 血契牙 | 刃器命中时恢复生命 |
| 回声铃 | 每三次武器主动施放产生额外震波 |
| 裂光透镜 | 每轮投射物追加一枚追踪折射弹 |
| 死火余烬 | 燃烧敌人死亡时爆燃 |

引雷针、霜纹镜、孢子囊、血契牙也能参与隐藏融合。触发效果有相应冷却，并禁止遗物伤害再次触发命中遗物，避免无限递归。状态面板显示实际累计效果、触发条件、可联动武器与本局触发次数。

升级池会提高适配当前武器的遗物权重，保留强化现有武器的机会；每逢 3 的倍数等级，在有空余选项时提供一件适配遗物。融合与配方追踪仍优先。

## 内容

- 3 位可选角色，各有起始武器与天赋。
- 10 系基础武器、10 种终焉进化、8 类属性祝福与 8 类联动遗物。
- 9 条隐藏融合路线：5 条双武器、4 条武器与遗物；永久发现记录、已知配方追踪与 3 级融合成长。
- 无限延伸的墓园、逐像素绘制的场景与角色、昼夜氛围、余烬与雾气。
- 经验吸取、升级三选一、每局三次重铸、可探索的祭坛与宝箱。
- 6 种基础敌人、精英怪、定时怪潮、3 次首领战与最终胜利。
- 10 分钟难度曲线：03:00、06:00 首领战，后半程提高敌人强度；中后期升级门槛更高，精英宝箱隔次怪潮出现。
- 冲刺残影、斩击、穿透弩矢、环绕游魂、连锁雷霆、持续火焰与冰霜脉冲。
- 由 Web Audio 实时合成的背景音乐与音效，无外部音频素材。
- 永久余烬祭坛、历史纪录与设置，保存在当前浏览器 localStorage。
- 原生 Canvas 2D + JavaScript，零运行时依赖。

游戏逻辑、像素素材和音频全部本地运行。页面的可选 Google Fonts 请求失败时会自动使用系统字体。

按要求未添加或运行测试。

## 文件

- `src/game.js` — 游戏循环、移动、战斗、生成、掉落与渲染。
- `src/art.js` — 原创像素精灵、地图分块与绘制工具。
- `src/data.js` — 角色、武器、祝福、敌人与存档结构。
- `src/audio.js` — Web Audio 合成音效与程序化配乐。
- `src/main.js` — 界面、输入、成长祭坛与结算。
- `src/stats.js` — 战斗与状态面板共用的角色、武器属性计算。
- `src/status.js` — 角色状态、装备效果、加成来源和查看时的暂停恢复。
- `src/fusions.js` — 融合配方、材料要求、等级继承与武器上限。
- `src/fusion-combat.js` — 日轮、雷弩和寒晶的攻击、领域、连锁与像素特效。
- `src/content.js` — 扩充武器、联动遗物、触发数值和适配关系。
- `src/content-art.js` — 扩充内容的原创 24×24 像素图标。
- `src/expanded-combat.js` — 月镰、毒池、钟波、光束及其融合形态的战斗与绘制。
- `src/relic-combat.js` — 联动触发、点燃、侵蚀、触发冷却和计数。
- `src/discovery.js` — 永久道具记录、历史最高等级与旧融合记录迁移。
- `src/catalog.js` — 道具图鉴、分类搜索、等级预览与已发现搭配。
- `src/item-info.js` — 装备面板与图鉴共用的效果说明与武器数值条目。
- `status.css` — 像素风状态面板与移动端布局。
- `fusion.css` — 配方图谱、材料追踪与融合升级卡样式。
- `catalog.css` — 图鉴、永久发现入口与移动端布局。
- `run-menu.css` — 远征菜单、重新开始与退出营地入口。
- `style.css` — 桌面和触屏界面。
- `server.cjs` — 仅绑定本机地址的静态服务器。
