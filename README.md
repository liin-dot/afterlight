# 烬夜 AFTERLIGHT · 长夜重铸

原创像素生存游戏：进入遗忘墓园，回收灵光，组合武器与遗物，活过十分钟并击败蚀月君王。原生 Canvas 2D、ES Modules 与 Web Audio，零运行时依赖。

## 启动

需要 Node.js，无需安装依赖：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173/>。也可部署到静态服务器；浏览器模块需要 HTTP 服务，不能直接打开 HTML 文件。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 幽影冲刺 | WASD、方向键 / 空格 |
| 选择升级 | 1、2、3 或点击 |
| 远征菜单 / 返回 | Esc、P |
| 角色状态 / 天赋树 / 融合手记 / 道具图鉴 | C / T / G / I |
| 菜单内重新开始 / 返回营地 | R / Q |
| 声音 / 全屏 | M / F |

触屏显示摇杆与冲刺按钮。武器自动攻击。状态、图鉴、菜单均暂停战斗；从升级页查看后返回会保留原来的选项。重新开始和退出营地会先结算余烬与发现记录。

## 角色与局内天赋

三名角色各有默认能力、三条天赋分支与九个节点，共 **3 种默认天赋、27 个升级节点**。默认能力从出征开始生效，不占武器或道具位置。

| 角色 | 默认能力 | 三条成长路线 |
| --- | --- | --- |
| 守灯人 | 自带 8 护盾；近身武器命中积蓄灯火，六层触发震荡并补盾 | 薪火：燃烧与震荡回响；灯壁：护甲、恢复、一次致命保护；征途：冲刺震荡与短时增伤 |
| 逐星者 | 一颗独立伴星自动发射追踪星火 | 星群：四伴星与穿透；寒月：减速、易伤、冻结；灵知：经验、拾取和回收灵光时恢复 |
| 荒野客 | 移动积蓄猎风，下次武器施放追加穿透风矢 | 穿风：投射物增伤与三重追踪；游猎：移速、冲刺与自动疾射；鹰眼：远距输出与暴击追击 |

等级 **4、8、12、18、24、30** 各获得一个天赋点，每局最多六点。节点消耗一点，同列依次学习；第三层从 18 级开放，三种最终专精只能选择一种，其余点数可投入其他分支的前两层。天赋不消耗装备升级三选一，投入后本局不可撤回，重开时全部重置。

营地可以预览完整天赋树；战斗 HUD 显示灯火、伴星或猎风状态，升级页在有未用点数时提示。按 **T** 打开天赋树会暂停战斗；学习后立即更新属性、装备预览与联动判断，返回升级页保留原选项、待选次数和重铸次数。结算伤害记录包含角色天赋造成的直接伤害。

天赋生成的追加攻击不会递归触发命中遗物或再次暴击。灼烧、冻结、治疗和补盾各自遵守描述中的间隔与上限；角色控制或燃烧能力也可为相关遗物提供触发条件。

## 本次重铸

总计 **81 种可发现道具**：16 种基础武器、20 种融合武器、14 种属性祝福、24 种联动遗物、7 种拾取物。基础武器的 16 种独立进化归入对应武器，不重复计数。

新增六件遗物：**牧魂契**强化灵魂与召唤武器、**霜行石**在冲刺起点冻结追兵、**腐时沙漏**强化附着燃烧与侵蚀、**碎灯棱片**在破盾时发射追踪棱片、**分岔骨钉**让武器暴击分裂追击、**蓄雷瓶**将雷电命中积成护身雷环。新增融合 **烬雪天灾**组合冻结陨星与冰火领域，**群星灵龛**组合穿透追魂召唤与消散震波。配方仍需要在游戏中亲手融合后揭晓。

- 新武器包括跳弹飞轮、延迟陨星、感应地雷、牵引锁链、固定石像与贯穿长枪。融合会组合攻击机制，例如陷阱加冻结、炮台加连锁、陨星加光束。
- 武器六格，属性祝福与遗物共用六个道具位。有限位置让输出、防御、控制与成长之间有取舍。
- 新属性包括范围、持续、弹数、暴击倍率、经验成长与诅咒。诅咒同时提升自身收益和敌方压力。
- 遗物可互相提供触发条件：寒髓针与霜纹镜、蚀骨针与孢子囊、不熄燃芯与死火余烬、护盾与反伤，以及火毒共存时的炼金爆炸。
- 升级卡显示实际数值变化、适配原因和消耗材料；状态页列出已生效组合，结算显示主要伤害来源和总伤害。遗物与次生效果合并计入单独一项。

## 十分钟节奏

`src/balance.js` 集中定义阶段、经验需求与选择权重。敌人生命、伤害、速度在分钟间平滑变化；敌群组成、密度与上限按阶段切换。

| 时间 | 战场变化 | 构筑重点 |
| --- | --- | --- |
| 00:00–02:00 | 骷髅、蝠群与食尸鬼逐步加入 | 提高主武器等级，获得第二种攻击手段 |
| 02:00–03:00 | 幽魂开始远射，开放武器独立进化 | 准备控制与第一组材料 |
| 03:00 | 墓园看守，开放隐藏融合 | 选择融合或继续独立进化 |
| 04:00–06:00 | 重甲单位增多，收割者出现 | 补足单体输出、防御和遗物联动 |
| 06:00 | 无名葬钟 | 利用攻击预警和冲刺处理首领 |
| 07:00–10:00 | 混合怪潮，幽魂散射，收割者蓄力突进 | 利用穿透、控制与清场补给维持路线 |
| 10:00 起 | 蚀月君王，降低普通敌群密度 | 躲避冲锋、地面预警和带缺口的环形弹幕 |

三分钟与六分钟首领登场后，普通生成放缓 22 秒。普通敌人生命由开局 1 倍升至十分钟 9.8 倍，伤害升至 2 倍；最终首领需要击败才算通关。永久祭坛提供温和的起步加成。

每级所需经验为 `round(8 + 4 × (等级−1) + 1.4 × max(0, 等级−5)^1.65)`。前期较快获得关键选择，后期升级成本逐渐增加。拾取范围和经验倍率分开成长；合并远处结晶时保留全部经验。

药草恢复 16 生命，满血时留在地上，掉落有共享间隔和地面数量上限；低生命且长时间无药草时提供补偿。冻结、清场、护盾、全场吸取是稀有战术补给。精英宝箱强化一次已有装备，首领宝箱强化两次并恢复 10 生命；满级或放逐装备不参与抽取。

## 权重与构筑

所有武器和道具有构筑标签：近战、远程、火焰、寒霜、雷电、侵蚀、灵魂、召唤、范围、控制、暴击、守护、游击、成长。猩红誓约、时隙沙漏等全局强化标为「通用」，不为所有流派重复投票。升级卡、道具状态和图鉴都会显示标签，图鉴也支持按标签名称搜索。

本局最近 **12 次主动装备选择**形成偏好。最新选择贡献 1 份信号，每向前一次乘 **0.82**；多标签道具平均分配信号，避免标签多就天然占优。现有装备提供较弱的基础信号（每件 `0.18 + min(4, 等级−1) × 0.04`）。候选的最强匹配标签加上第二匹配的四分之一，形成 `1 + 1.6 × min(1, 信号 / 3)` 倍率，最高 **×2.6**。

选择火焰会逐渐提高火焰及相关范围道具的权重，转向寒霜后旧信号衰减，新的控制、冰雷搭配更容易出现。只记录实际选择成功的装备与融合；查看、重铸、放逐、跳过、宝箱和天赋学习不冒充主动装备选择。宝箱强化会改变当前装备的弱信号。本局偏好重开即清空。

常见、精良、稀有的基础权重为 **100 / 70 / 42**，不是最终抽中概率。已有武器乘 2.25、已有道具乘 1.7；有触发来源的遗物乘 1.8，缺少来源的乘 0.22。相关融合材料乘 1.25、补齐遗物触发来源乘 1.8、角色专长乘 1.18，最后再乘标签倍率。降低固定偏置，让本局实际选择发挥更大的作用。

升级尽量保留一项已有武器强化，开局优先提供第二种武器；每四级在有剩余选项时提供适配遗物。可用融合、已发现且正在追踪的材料优先。满槽、满级、已消耗或已放逐的装备不会挤占不适用的选项。

从 5 级开始，若保底选择后仍有空位，有 **22%** 的机会抽取一件标签加权较弱的新装备，标为「转型机会」；需要有可用装备位，遗物也须具备触发来源。其余候选仍正常按权重抽取，不匹配的标签不会被清零。卡上的「标签加权」仅表示标签倍率，不能当作最终出现概率。

每局有三次重铸和三次放逐。重铸降低上一组选项再次出现的权重；放逐刷新选择，并让该装备退出本局升级与宝箱池，已有属性保留但不释放位置。也可跳过当次成长换取 10 余烬。无可用升级时改为治疗与余烬。

武器及预览共用 `src/stats.js`。持续状态伤害不暴击，也不重复触发命中遗物；连锁、尸爆、汲取和反伤各有对应限制。护甲减伤仍保留至少 30% 的原始伤害，护盾按上限补充，不能无限累加。

## 发现与融合

三分钟后，双武器路线需要指定武器各四级，武器与遗物路线需要武器五级、遗物二级。未知配方照常判定，满足后升级会出现未知融合卡；亲手选择并成功融合才揭晓成品并永久记录。

融合消耗材料的全部等级，材料的独立效果失去且本局不再出现。双武器合为一格；消耗遗物会释放一个道具位。成品从一级开始，每件六级武器或满级遗物贡献一级继承，最高三级。宝箱只强化，不自动融合。

图鉴记录实际获得的道具及最高等级，支持搜索、分类、各级数值和已发现搭配。配方追踪仅用于已发现的路线。继续使用原 localStorage 存档，保留余烬、祭坛、战绩和已有发现；旧融合记录可补录其材料的最低已达等级，未曾保存的普通道具获取历史无法追溯。

## 检查

```sh
npm run check
npm run check -- --weights
npm run check -- --simulate
node tools/check-balance.mjs --browser
```

同一个原生 Node 检查脚本覆盖全部武器数值、72 次实际攻击、20 条融合交易、六格约束、标签覆盖、偏好累积与转型、权重上限、触发条件、六件新遗物、护盾与补给，以及 27 个天赋节点的学习条件、六点上限、重置、默认能力、伴星控制、冲刺、震荡回响和一次致命保护。模拟使用实际游戏循环并花费天赋点，输出三名角色的生存代理和关闭受伤的收集代理结果到 `artifacts/balance-report.json`。它用于比较成长节奏，不代表真人通关率。

`--weights` 固定同一套装备、角色、时间与随机种子，为无偏好、火焰偏好、寒霜转型各抽取 600 组三选一，结果写入 `artifacts/weight-report.json`。多标签道具会同时计入多个标签，因此标签计数不应相加作为总候选数。

浏览器检查需先启动本地服务，并安装 Windows 版 Chrome（脚本使用默认安装路径）。它检查桌面、触屏布局，升级倾向、标签搜索、放逐、两条新增融合、结算、三名角色的天赋树、键盘与触屏学习、专精锁定及返回时保留升级选择，并保存截图到 `artifacts/`。截图与临时浏览器配置不进入版本控制。

设计参考：[Vampire Survivors 官方 Adventures FAQ](https://poncle.games/adventures-faq) 的有限武器池与成长取舍，以及 [《20 Minutes Till Dawn》官方介绍](https://store.steampowered.com/app/1966900/20_Minutes_Till_Dawn/) 的角色独特能力与局内构筑。本作的十分钟流程、角色天赋、道具、组合与具体数值均为独立设计。像素素材、游戏逻辑和合成音频本地运行；可选 Google Fonts 不可用时回退系统字体。
